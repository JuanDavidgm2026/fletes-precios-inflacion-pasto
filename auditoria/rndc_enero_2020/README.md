# Auditoría RNDC — enero de 2020

Esta carpeta contiene las evidencias de reconstrucción y validación de los registros del Registro Nacional de Despachos de Carga (RNDC), correspondientes a enero de 2020.

**Fuente:** Ministerio de Transporte de Colombia.

**Cobertura:**
- Registros nacionales: 134.426.
- Registros con destino a Pasto: 1.156.
- Columnas contrastadas: 23.

La auditoría permite verificar la correspondencia entre el archivo mensual original, el extracto de Pasto y el maestro procesado utilizado en la investigación.

**Limitación:** la conciliación directa desde el archivo mensual original corresponde únicamente a enero de 2020.
